# Lucas Tavano · Cursos de IA

Landing de venta de los cursos de IA con salida laboral (10 cursos). Sitio estático: no necesita build.

- `index.html`: la landing (modo claro/oscuro, precios ARS/USD, WhatsApp)
- `manifest.webmanifest`, `sw.js`, `icon.svg`: para instalarla como app (PWA)

Para publicarla en Vercel: importá este repositorio, sin framework, sin comando de build.
